# Creative 3D Benchmark — Voxel Floating Island

Category: **Creative 3D Generation / Voxel World**

This is a new benchmark category for the LM Studio Optimiser. It moves beyond
"tokens per second" and asks: *can the model actually build a usable 3D scene?*

## Structure

```
voxel_island/
├── runtime/                # Benchmark runtime (fixed, not generated by model)
│   ├── index.html          # Shell: canvas, HUD, controls
│   ├── runtime.js          # Docs
│   └── vendor/
│       ├── three.module.js   # Three.js ES module (vendored, no network)
│       └── jsm/
│           └── controls/
│               └── OrbitControls.js
├── prompts/
│   └── voxel_island.txt    # The fixed prompt every model receives
├── runner/
│   └── playwright_runner.js # Headless Chromium test harness
├── results/                # Output: screenshots + result.json
├── scoring.md              # Scoring rubric
└── README.md               # this file
```

## How it works

1. The optimiser sends `prompts/voxel_island.txt` to the model.
2. The model returns `scene.js` exporting `createScene({ THREE, random })`.
3. `runtime/index.html` loads Three.js, imports `./scene.js`, calls
   `createScene()`, and renders with orbit controls.
4. `runner/playwright_runner.js` opens the page in Chromium, takes screenshots
   before/after camera rotation, reads the HUD, and writes `results/result.json`.

## What the model must NOT generate

No HTML, CSS, camera, lights, renderer, OrbitControls, or `index.html`. Those
belong to the runtime. The model generates only procedural 3D geometry in a
single `THREE.Group`.

## Example model output

```js
export function createScene({ THREE, random }) {
  const root = new THREE.Group();
  root.name = "VoxelIsland";
  // ... build terrain, trees, waterfall ...
  return root;
}
```

## Scoring

See `scoring.md`. Automatic checks (JS parses, group returned, named groups,
camera rotates, screenshots differ) plus optional vision-model quality rating.

Generation speed (tok/s) is reported separately and is NOT mixed into quality.

## Running

```
# 1. Vendor Three.js (one-time):
#    download three.module.js + OrbitControls into runtime/vendor/

# 2. Put the model's scene.js into voxel_island/

# 3. Run the playwright runner:
npx playwright run runner/playwright_runner.js

# 4. Read results/result.json
```
