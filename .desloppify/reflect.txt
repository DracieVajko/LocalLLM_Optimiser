## Cluster Blueprint
Cluster "cli-workflow-extraction" (lm_optimizer/cli/main.py) — extract preflight, host lifecycle, run execution and report rendering from the 603-line optimize/auto bodies; rename internal helpers by responsibility. Four findings share the same file and root cause.
Cluster "settings-boundary-typing" (services/optimizer.py, api/routes.py, cli/main.py, services/lmstudio_defaults.py) — one AdvancedSettings boundary object, one BenchmarkService factory, and typed shapes for defaults/duel payloads; this also removes per-layer default logic.
Cluster "error-handling-audit" (services/optimizer.py, api/routes.py, cli/main.py) — replace copied except/pass blocks with a logged best-effort helper, document layer contracts, and flatten retry/success conditions.
Cluster "api-contracts" (api/routes.py, api/schemas.py, api/main.py) — add response models, one exception mapping, one presenter path, and replace the manual router surgery with a supported registration pattern.
Cluster "services-structure" (services/, discovery/, domain/models.py) — split the flat services package by capability, break the domain hub, and port discovery/inspector.py to services/lm_studio.py before deleting api/client.py.
Cluster "report-and-test-config" (services/reporting.py, services/optimizer.py) — split report section builders and the 244-line _test_config into load/measure/evaluate/record steps.
Cluster "tests-conventions" (tests/, lm_optimizer/tests/) — decide one canonical root or document unit vs integration markers; add httpx.MockTransport contract tests for host clients.
Cluster "security-and-docs" (api/routes.py, web_main.py, services/reporting.py) — add an optional API token for remote bind and align long-function docstrings with their side effects.
